# Number Guessing Game 🎮

Terminal game built in Python — guess a number between 1-100.

## Features
- 3 difficulty levels (Easy / Medium / Hard)
- Score rating after winning
- Full guess history shown at end
- Input validation — handles bad input cleanly

## Concepts used
Lambda · List comprehension · try/except · for/else · Functions

## How to run
```
python game.py
```
